# Project Status

## Objective

Build a practical online hiring system for `Pet Supplies Plus Battle Creek` under `Battle Creek Pets LLC` that:

1. Filters applicants for schedule fit first
2. Screens for pay expectations early
3. Helps managers move qualified applicants to interview faster
4. Stays lightweight enough for a small business to operate

## Current MVP

The prototype currently includes:

1. Multi-step applicant application flow
2. Availability matrix with weekend and evening screening
3. Pay-range checkpoint
4. Fit questions focused on retail readiness
5. Automatic candidate scoring
6. Manager dashboard
7. Candidate stage tracking
8. Manager notes
9. CSV and JSON export
10. Store-specific settings saved locally for testing
